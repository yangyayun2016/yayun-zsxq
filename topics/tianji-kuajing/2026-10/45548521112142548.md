\## 一、广告打法选择框架

\### 1.1 打法选择前置三问

在选择任何广告打法之前，必须先回答：

| 前置问题 | 说明 |

|----------|------|

| **\*\*品类属性是什么？\*\*** | 标品/非标品；大词垄断还是长尾分散；竞争激烈程度 |

| **\*\*广告目的是什么？\*\*** | 曝光/收录/排名/转化/利润/防御/爆品，目的不同打法完全不同 |

| **\*\*当前推广阶段？\*\*** | 新品期 / 成长期 / 成熟期 / 促销期 / 防守期 |

\> **\*\*核心原则：\*\*** 没有万能打法，只有适合当前目标、阶段和品类的打法。找到"生态位"——有销量且有利润的稳定位置，才是终极目标。

\### 1.2 打法总览地图

\`\`\`

广告打法（30+）

  ├── 基础目标类（1–8）：曝光/收录/排名/转化/首位/ACOS/进攻/防御

  ├── 流量扩张类（9–18）：爆品/霸屏/海王/海量词/关联/ASIN/类目/品牌/捡漏/小众/小语种

  ├── 关键词精细类（19–27）：词根/高频词/特征词/属性词/时间差/马甲/全域/前置否/搜索词拓展

  └── 精品战略类：天机打法（5–6核心词精准占位）

\`\`\`

\## 二、基础目标类打法（1–8）

\### 打法 1：打曝光

**\*\*目标：\*\*** 最大化展示量，建立产品认知，适合新品冷启动和品类教育。

**\*\*核心逻辑：\*\*** 先让消费者"见过你"，再谈点击和转化。

| 要素 | 操作细节 |

|------|----------|

| **\*\*广告类型\*\*** | SP自动广告（全类型开启）+ SB品牌广告 |

| **\*\*匹配方式\*\*** | 宽泛匹配为主，低竞价广撒网 |

| **\*\*竞价策略\*\*** | 固定竞价 或 动态竞价-仅降低 |

| **\*\*竞价水平\*\*** | 建议竞价的60%\~80%，低价获取最大曝光 |

| **\*\*预算\*\*** | 充足预算，保证全天不断投 |

| **\*\*否词\*\*** | 极少否词，最大化曝光面 |

| **\*\*核心指标\*\*** | 曝光量（Impressions）、展示份额 |

**\*\*适用场景：\*\*** 新品上线前7天；新品类教育期；提升品牌知名度。

**\*\*注意：\*\*** 打曝光阶段ACOS会偏高，属正常现象，不要因为ACOS高就暂停。

\---

\### 打法 2：打收录

**\*\*目标：\*\*** 让亚马逊算法将你的ASIN与尽可能多的相关关键词关联，扩大被自然搜索到的范围。

**\*\*核心逻辑：\*\*** 收录的关键词数量 × 关键词相关性 = 自然流量底盘。

| 要素 | 操作细节 |

|------|----------|

| **\*\*Listing端\*\*** | 标题/五点/描述/后台Search Terms全部埋入目标词；A+文案也要布词 |

| **\*\*广告端\*\*** | SP自动广告全开，让系统发现关联词；手动宽泛匹配覆盖变形词 |

| **\*\*关键词来源\*\*** | 竞品反查 + 词根延伸 + 品类拓词，建立词库 |

| **\*\*核心指标\*\*** | 收录关键词数量（可用卖家精灵/SIF查询） |

| **\*\*优化动作\*\*** | 定期对比竞品流量词，把不相关词否定掉，把高相关词拉进来 |

**\*\*收录优化两个核心维度：\*\***

1\. **\*\*收录词数量\*\*** → 覆盖面，用宽泛投放+自动广告扩展

2\. **\*\*收录词质量（相关性）\*\*** → 用否定词清理偏离词，拉高整体相关性得分

**\*\*核心动作：\*\***

\`\`\`

多个竞品ASIN流量对比分析

→ 找出竞品有、自己没有的高流量相关词

→ 补入Listing文案 + 广告投放

→ 用自动广告验证是否被收录

→ 定期清理不相关词（否定），提升收录质量

\`\`\`

\---

\### 打法 3：打排名

**\*\*目标：\*\*** 提升核心关键词的自然搜索排名，降低长期流量成本。

**\*\*核心逻辑：\*\*** 广告点击+转化 → 关键词排名权重↑ → 自然排名上升 → 自然出单↑ → TACOS↓。

| 要素 | 操作细节 |

|------|----------|

| **\*\*选词\*\*** | 聚焦3\~5个核心出单词，不要分散兵力 |

| **\*\*广告类型\*\*** | SP手动精准匹配，集中预算砸核心词 |

| **\*\*竞价策略\*\*** | 动态竞价-提高和降低，攻首页顶部位置 |

| **\*\*广告位\*\*** | 搜索结果首页顶部溢价 50%\~100% |

| **\*\*辅助手段\*\*** | 站外流量引流至核心词搜索路径；Deals/促销配合拉转化 |

| **\*\*监控\*\*** | 每小时监控核心词坑位排名变化 |

**\*\*排名提升飞轮：\*\***

\`\`\`

广告打首页 → 获得点击 → 有转化 → 关键词eCPM↑ → 自然排名↑ → 自然流量↑ → 更多转化 → 排名继续↑

\`\`\`

**\*\*注意：\*\*** 打排名要配合\*\***打转化（打法4）\*\***，没有转化率支撑的排名会快速回落。

\---

\### 打法 4：打转化

**\*\*目标：\*\*** 优先选择高意图流量，最大化广告订单转化率，降低ACOS。

**\*\*核心逻辑：\*\*** 宁可少点击，也要高质量点击。

| 要素 | 操作细节 |

|------|----------|

| **\*\*广告类型\*\*** | SP手动精准匹配为主 |

| **\*\*关键词选择\*\*** | 有历史转化数据的精准词；长尾高意图词 |

| **\*\*匹配方式\*\*** | 精准匹配（Exact）；严格控制流量质量 |

| **\*\*竞价策略\*\*** | 动态竞价-提高和降低 |

| **\*\*否词\*\*** | 积极添加否定词，过滤低转化流量 |

| **\*\*核心指标\*\*** | CVR（转化率）、ACOS |

**\*\*前置条件检查（无这些条件转化打不好）：\*\***

\- \[ \] 有货 + Prime资格

\- \[ \] 首选购买按钮（Featured Offer）≥90%

\- \[ \] 评分≥3.8，评价≥10条

\- \[ \] 主图吸引力强，价格有竞争力

\- \[ \] Listing信息完整，规格参数清晰

\---

\### 打法 5：打首页首位

**\*\*目标：\*\*** 占据搜索结果页第一位，获取最高质量流量，快速拉升排名。

**\*\*核心逻辑：\*\*** 首页首位是流量金矿，CTR和CVR通常是其他位置的2\~3倍。

| 要素 | 操作细节 |

|------|----------|

| **\*\*广告类型\*\*** | SP手动精准 |

| **\*\*广告位溢价\*\*** | 搜索结果首页顶部 溢价 80%\~100%（上限100%） |

| **\*\*竞价策略\*\*** | 动态竞价-提高和降低 |

| **\*\*竞价水平\*\*** | 参考建议竞价 × 1.2\~1.5，确保稳居首位 |

| **\*\*预算\*\*** | 必须保证全天预算充足，不能断投 |

| **\*\*监控\*\*** | 每小时检查坑位排名，确保持续占位 |

| **\*\*配合\*\*** | 同步开SB广告覆盖同一关键词，双重占位 |

**\*\*成本控制：\*\*** 首位竞价高，须确保CVR足够支撑ACOS目标。建议仅对核心词（3\~5个）打首位，其余词控制成本。

\---

\### 打法 6：打ACOS（控利润）

**\*\*目标：\*\*** 在保证出单的前提下，将ACOS压缩到目标范围，实现广告盈利。

**\*\*核心逻辑：\*\*** 精细化筛选流量，提高每分广告费的回报率。

| 要素 | 操作细节 |

|------|----------|

| **\*\*选词原则\*\*** | 只投有转化历史的词；砍掉高花费0转化词 |

| **\*\*竞价操作\*\*** | 每周检查，高ACOS词降价10%\~20%；低ACOS词适度提价扩量 |

| **\*\*否词执行\*\*** | 30天点击≥20次0转化 → 立即否定 |

| **\*\*广告结构\*\*** | 自动广告发现词 → STR转移到手动精准 → 自动组否定该词 |

| **\*\*核心指标\*\*** | ACOS、CPA（每订单成本）、毛利率 |

| **\*\*目标设定\*\*** | 目标ACOS = (1 - 利润率) × 100%；低于此值才真正盈利 |

**\*\*ACOS优化四步法：\*\***

\`\`\`

① 找出ACOS最高的词/搜索词 → 降价或否定

② 找出ACOS最低但出单少的词 → 提价扩量

③ 将自动广告高转化词转移至手动精准

④ 压缩宽泛/词组匹配比例，集中精准匹配

\`\`\`

\---

\### 打法 7：打进攻

**\*\*目标：\*\*** 主动进攻竞品流量，把竞品的购买用户截流到自己产品。

**\*\*核心逻辑：\*\*** 在竞品详情页和搜索页拦截高意图竞品用户。

| 打法类型 | 操作方式 |

|----------|----------|

| **\*\*竞品词投放\*\*** | SP手动精准投放竞品品牌词/竞品型号词 |

| **\*\*竞品ASIN定向\*\*** | SP/SD商品定向，选价格更高、评分更低的竞品 |

| **\*\*SB竞品词\*\*** | 品牌推广覆盖竞品搜索词，截取品牌搜索流量 |

| **\*\*SD展示再营销\*\*** | 对浏览过竞品ASIN的用户定向展示 |

**\*\*进攻目标选择原则：\*\***

\- 优先选价格比自己高的竞品

\- 优先选评分比自己低的竞品

\- 优先选评价数量比自己少的竞品

\- 优先选近期差评多的竞品

**\*\*注意：\*\*** 进攻打法转化率通常低于核心词投放，需要设置独立广告活动，单独控制预算和ACOS目标。

\---

\### 打法 8：打防御

**\*\*目标：\*\*** 保护自己的产品页面和品牌词流量，防止竞品截流。

**\*\*核心逻辑：\*\*** 守住已有流量阵地，让竞品广告无法出现在自己的产品页和品牌词搜索中。

| 防御层次 | 操作方式 |

|----------|----------|

| **\*\*品牌词防守\*\*** | SP精准投放自身品牌词，阻止竞品品牌词广告抢占 |

| **\*\*ASIN自投放\*\*** | SD定向自身ASIN，防止竞品展示广告出现在自己产品页 |

| **\*\*SB品牌词覆盖\*\*** | 品牌推广覆盖自身品牌词，占据搜索页顶部 |

| **\*\*爆品保护\*\*** | 对核心SKU全方位自投，覆盖SP+SB+SD三类广告 |

**\*\*何时必须开启防御？\*\***

\- 产品已有一定市场份额

\- 品牌词有明显搜索量

\- 发现竞品在自己ASIN页面投放广告

\- 大促前后流量保卫期

\## 三、流量扩张类打法（9–18）

\### 打法 9：打爆品

**\*\*目标：\*\*** 在短期内快速放大出单量，冲击BSR排名，形成销量飞轮。

**\*\*核心逻辑：\*\*** 集中资源打爆一款产品，利用销量带动排名，排名反哺流量和转化。

**\*\*爆品打法四要素：\*\***

| 要素 | 操作 |

|------|------|

| **\*\*选品质量\*\*** | 爆品前提：Listing完整、评价基础、价格有竞争力 |

| **\*\*广告爆发\*\*** | 核心词全部抢首位，预算是平时3\~5倍 |

| **\*\*促销配合\*\*** | 同期上Coupon + 折扣，提升页面吸引力和转化率 |

| **\*\*库存保障\*\*** | 爆品期间库存必须充足，断货前暂停广告 |

**\*\*爆品节奏：\*\***

\`\`\`

前期（D1\~D7）：打曝光+打收录，建立流量基础

中期（D8\~D30）：打排名+打首位，冲击BSR

爆发期：配合Deals/BD/LD，集中放量

维持期：打转化+打ACOS，维持利润

\`\`\`

\### 打法 10：打霸屏

**\*\*目标：\*\*** 在搜索结果页同时占据多个广告位（SP首位 + SB顶部 + SD侧边），形成视觉垄断。

**\*\*核心逻辑：\*\*** 同一搜索页多位置同时展示，消费者无论看哪里都能看到你，提升品牌认知和点击概率。

**\*\*霸屏组合：\*\***

\`\`\`

搜索结果页

  ├── \[顶部\] SB品牌推广广告（Banner位）

  ├── \[第1\~2位\] SP商品推广（首页顶部溢价）

  ├── \[中间穿插\] SP商品推广（搜索其余位置）

  └── \[侧边/底部\] SD展示型推广

\`\`\`

**\*\*操作要点：\*\***

\- 同一关键词在SP、SB、SD三类广告同时投放

\- SP打精准匹配，SB打品牌词+类目词，SD打商品定向+再营销

\- 须有充足预算支撑，通常为单一广告的3\~4倍

**\*\*适用场景：\*\*** 大促冲刺期；竞争激烈类目中拉开差距；品牌建设阶段。

\### 打法 11：打海王（广撒网低成本）

**\*\*目标：\*\*** 以极低CPC广泛曝光，用最低成本挖掘潜在出单词。

**\*\*核心逻辑：\*\*** 竞价远低于市场均值，只抢剩余流量（Leftover Traffic），成本极低，以量取胜。

| 要素 | 操作细节 |

|------|----------|

| **\*\*竞价\*\*** | 建议竞价的30%\~50%，极低出价 |

| **\*\*匹配方式\*\*** | 宽泛匹配为主 |

| **\*\*关键词数量\*\*** | 大量词（100\~500个），广泛覆盖 |

| **\*\*竞价策略\*\*** | 动态竞价-仅降低，严控成本 |

| **\*\*目的\*\*** | 捕捉市场上的低竞争流量；发现意想不到的出单词 |

**\*\*海王 vs 精准打法对比：\*\***

| 维度 | 海王打法 | 精准打法 |

|------|----------|----------|

| 竞价 | 极低 | 较高 |

| 流量质量 | 参差不齐 | 精准高质 |

| 成本 | 极低 | 较高 |

| 发现新词 | 能力强 | 能力弱 |

| 适用阶段 | 探索期/辅助 | 成熟期/主力 |

\### 打法 12：打海量词收录（全量关键词10万个）

**\*\*目标：\*\*** 尽可能多地被亚马逊算法收录，建立最宽泛的流量入口网络。

**\*\*核心逻辑：\*\*** 收录的词越多，被搜索到的机会越多；通过算法筛选，留下真正有价值的词。
