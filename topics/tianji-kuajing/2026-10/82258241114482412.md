亲测：我最近一直有在测试几个最新的个人智能体，我来谈谈这几个personal agent，说说我的看法

总结

Instinct 是 personal agent，Muse 可能是 personal agent，但 Grokbot 不是，它也不想是 personal agent。Grokbot应该是 person-like agent，祖宗是 之前爆火的小龙虾 OpenClaw，本质是把 Agent 几乎无限的能力范围封装到一个 IM 对话下，降低用户心智负担。

Instinct 是 personal agent——他们靠用户在产品中产生的交易抽成赚钱。Grokbot 需要帮你在云端/本地电脑上面做所有事情。 对于多数普通人来说，Grokbot 他想取代的是 Codex/Claude，根本不是什么 personal agent。

特别是最近几天，我把 200 美金的 Codex 退订之后， Claude Code 又被封号的情况下，把几乎所有的活通通挪到了 Grokbot。惊讶地发现，Grokbot 可能是因为用了 Opus 5.5 的缘故，产出成果质量都远高于过去。在体验远远好于 Codex 的基础上，工作质量又能达到 Claude Code 的八成。

Instinct 靠用户在产品中产生的交易抽成赚钱，Meta 的muse靠用户交互数据精准卖广告赚钱，Grokbot 靠订阅费赚钱——你烧 token 越多，他们赚钱越多。所以很简单，他们希望你在上面干所有的事。天天在上面买机票、叫 Uber 能烧几个 token？

但是大家往往把他们定位成一类产品， 那他们应该是 person-like agent，祖宗是 OpenClaw，本质是把 Agent 几乎无限的能力范围封装到一个 IM 对话下，降低用户心智负担。

• 自主任务处理（完全放手 )多智能体团队协作（开个群会） 跨设备运行（无缝衔接

最后讲讲cue, manus的 cue 核心特点与功能 独立身份（Independent Identities）：每个智能体都拥有专属的电子邮箱、电话号码、数字钱包和独立的计算机环境,**多智能体团队协作（Group Chats）**：你可以把多个 Agent 放在同一个群聊里，为它们设定共同目标（例如：一个负责调研、一个负责筛选、一个负责起草方案），由它们协作推进。
