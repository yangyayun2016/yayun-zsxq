# 亚马逊精细化选品决策技能（Amazon Product Selection）

## 0. 技能定位与核心理念

**一句话定位**：把"凭感觉选品"变成"证据驱动的漏斗式决策"——以 15 个母维度为骨架、M1–M11 为采集流水线、15 项审核 + 9 项加权评分为闸门，最终输出「通过 / 待人工确认 / 否决」三类结论，每个结论必须带数据来源、快照日和统一口径。

**首要任务**：① 采集证据 → ② 逐维度打分（N 已验证 / U 未知 / F 否决）→ ③ 加权评分与推荐指数 → ④ 输出证据卡 + 决策建议。**Ally 负责抓取、计算、整理、成卡；是否进入、报价、备货等商业决策由用户拍板。**

**核心原则**：

1. **证据驱动**：任何结论附数据来源 + 抓取日期（快照日）+ 口径说明；官方数据 > 插件估算 > 工具推算，分层标注。
2. **先否决后比较**：知识产权（M11）、合规准入出现 F 级 → 直接终止，不再比较机会分。
3. **口径未确认不代填**：财务（M8-A）与供应链（M8-B）标注【待人工确认口径】的指标，一律先拆分、逐项与用户确认公式/周期/成本项/假设/数据源；未确认前输出占位符 + 确认清单，状态永远标 U，不许猜。
4. **实时数据有时效**：前台月销、BSR、CPC 等快照只在抓取当日有效；报告必须标注"快照日"。
5. **集中度分三层**：卖家、品牌、商品集中度必须分开计算，禁止合并成一个数。
6. **持续进化**：每次执行后把"该子类目实际阈值、验证过的坑"沉淀回本 SKILL（例如德国站某类目真实退货率基线），让技能越用越准。

## 1. 输入与输出

**输入**：

* 候选类目 / 核心关键词 / 站点（默认 Amazon.de，可参数化 US/UK 等）
* 目标价格带、目标参数与功能特征清单（M11 检索对象）
* 成本与预算数据（采购价、头程、关税、FBA、税费）
* 用户偏好：评分权重档位、阈值、XLSX/HTML 输出开关
* 【待人工确认口径】清单（§8）——开工前与用户过一遍，未确认项在报告中显式标注

**输出物清单**：

1. 《类目体检报告》HTML —— 全模块结论汇总 + 证据 + 决策建议（§6.6 章节结构）
2. 《TOP100 ASIN 实时销量库》XLSX —— 前台逐条抓取（§6.1 列规范）
3. 《核心竞品历史档案》XLSX —— SIF 拉取历史销量/流量（§6.1+补充列）
4. 《TOP10 竞品拆解表》XLSX —— 深筛卡格式（§6.2）
5. 《价格测算表》XLSX —— M3 单位经济全链路（§6.3）
6. 《VOC 结论卡》+《人群画像卡》（§6.4）
7. 《15 项审核 + 9 项加权评分卡》—— §5，深筛展开卡形态
8. 《知识产权检索报告》（§6.5）
9. 决策建议卡：通过 / 待人工确认 / 否决（含原因与证据）

| 数据源 | 用途 | 优先级 | 关键口径 / 注意 |
|----|----|----|----|

| 卖家精灵 | 自营比例、在售链接数、新品销量占比、类目销量占比、卖家垄断/集中度、商品与品牌集中度 | ★★★ 结构层 | 卖家集中度与品牌集中度分开算；新品占比口径（近6月/近1年）必须标注 |

| 极目工具 | 类目转化率交叉验证 | ★★ | 仅作参考系，不单独定结论 |
| Google Trends | 季节性、长周期兴趣曲线 | ★★ | 看 3–5 年曲线识别峰值月份与趋势方向 |

| AllyHub 智能分析 | TOP100 ASIN 批量抓取、竞品拆解、Score 效率值、VOC 初筛 | ★★★ 智能层 | 产出拆解表/结论卡，关键字段人工复核 |

| P4 质量信号 | M4 退货率 / M5 转化率 | 退货高不高？类目转化达不达标？ | 退货/转化结论卡 |

## 4. 模块详解

### M1 类目大盘与 TOP100 实时销量（前台 + SIF）

**目标**：回答"市场真实容量 + 头部格局 + 谁能对标"。

**步骤**：

1. **锁定目标类目**：核心关键词前台搜索 → 确认 Bestseller 类目节点（BSR 路径）。
2. **TOP100 实时销量抓取**：类目 Bestseller 榜（跨子类目合并去重，去重键 = ASIN），逐条记录 ASIN、BSR（大类+子类）、官方月销、评论数、评分、售价、变体数、上架时间（如可见）、主图。批量抓取由 AllyHub 执行，保留快照日。**采集纪律：滚动-点击-提取交错进行，不一次性滚到底再提取（防 DOM 回收与漏项）。**
3. **核心竞品圈定**：从 TOP100 筛出"参数、价格、目标人群与自己接近"的 ASIN（3–10 个；允许纳入低评论高销量的结构相似 ASIN）。
4. **SIF 历史拉取（核心竞品）**：逐 ASIN 导出历史销量曲线（覆盖 ≥6–12 个月）、历史流量曲线（总流量 + 自然 vs 广告曝光占比）、关键词排名轨迹（可选，供 M7）。
5. **输出**：TOP100 实时销量库 + 核心竞品历史档案（XLSX）。

**判定参考**（阈值按类目校准并在报告中声明）：头部月销中位数过低 → 容量存疑；核心竞品自然流量占比长期过低（持续靠广告）→ 广告依赖度高，M7 成本预警。

### M2 类目结构体检（卖家精灵）

**目标**：判断"能不能进、是不是卖家友好"。

**采集指标**（卖家精灵类目分析页）：

1. **亚马逊自营比例**（链接数与销量两个口径分别看）；
2. **在售产品链接数**（供给密度；剔除变体虚增）；
3. **新品销量占比**（标注插件口径：近 6 月/近 1 年）；
4. **类目销量占比分布**（头部 vs 长尾）；
5. **卖家垄断 / 卖家集中度**：CR3 / CR5 / CR10；
6. **商品与品牌集中度**：商品 CR3/CR10、品牌 CR3/CR10 —— **商品、品牌、卖家三层分开输出**。

**判定参考**：自营销量占比过高 → 环境不利；在售链接过密而有效流量有限（供给密度陷阱）→ 新品难获曝光；集中度过高 → 突破成本高；新品销量占比过低 → 类目对新品不友好。

### M3 价格带与单位经济（价格测算）

**目标**：确定"能赚钱的价格带 + 目标价全链路利润"。

**步骤**：

1. **价格带分布**：基于 TOP100 实际售价做价格带直方图（销量占比 + 款式占比双口径），识别主价格带与空档带（示例分带：0–5、5–10、10–15、15–20、20–25、25–30、30–35、35–40、40–45、45–50…€）。
2. **目标价位确定**：主价格带销量占比 ≤60%（防过度拥挤）、留促销空间（日常价–促销价–秒杀价三级）。
3. **单位经济测算**（一 SKU 一张表）：售价 − 佣金 − FBA − 头程分摊 − 关税/税费 = 毛利；算毛利率、盈亏平衡点、促销损耗、全生命周期 ROI 粗算（衔接 M8-A，注明口径待确认）。
4. **反推广告承受力**：盈亏平衡 ACOS ≈ 毛利额/售价 → 传导 M7 校验目标 CPC 可实现性。

### M4 退货率（商机探测器 / 选品指南针）

**目标**：识别"退货黑洞"类目。

* 取**目标子类目**退货率（商机探测器类目视图 + 选品指南针交叉验证）；
* 对比类目均值；显著偏高（示例参考 >10–15%，按品类校准）→ 预警并进 M10 查退货差评根因（能否设计规避）；
* 同时看头部竞品差评中"退货"关键词频次。

### M5 类目转化率（商机探测器 / 极目）

**目标**：拿到支持广告经济模型的类目平均转化率。

* 商机探测器 → 目标细分市场 → 【商品】与【搜索词】两维度平均转化率交叉取中值；
* 极目/广告后台验证（如有）；
* 输出类目平均转化率区间 + 来源口径；直接代入 M7 目标 CPC 公式与 M3 盈亏测算。

### M6 季节性与趋势（历史 + Google Trends）

**目标**：判断进场时机与备货节奏。

* 核心竞品 SIF 历史销量曲线 → 峰值月份、淡旺季倍率；
* 类目历史流量曲线同步看；
* Google Trends 近 3–5 年曲线：是否强季节性、长期向上/向下/平台、当前所处阶段（爬坡/峰值前/衰退）。
* 输出：旺季月份、备货提前期建议、淡季资金占用警示（写入 M8-A 前提）。

### M7 广告与竞争经济性（广告后台）

**目标**：回答"推广贵不贵、能不能做、节奏怎么打"。

**关键公式**（本技能标准口径）：

* **目标 CPC = 目标 ACOS × 客单价 × 广告点击转化率**
* 盈亏平衡 ACOS = 单位毛利额 / 售价（广告前利润口径）
* CPA = CPC / 转化率；ACOS = CPC /（客单价 × 转化率）

**步骤**：

1. **竞争与 CPC 采集**：广告后台核心关键词 → 记录建议竞价/CPC 区间、竞争商品数（卖家精灵交叉）；有历史广告数据时看实际运行 CPC。
2. **广告点击转化率**：类目平均转化率（M5）× 经验折扣系数（新品 listing 通常低于类目均值；系数与用户确认并注明）。
3. **可行性判断**：估算实际 CPC ≤ 目标 CPC（盈亏平衡 ACOS × 客单价 × 转化率）才可行；否则给"需降价 / 需优化转化 / 广告不可行"结论。
4. **推广节奏建议**（策略框架，落地由用户按账号情况定）：
   * 冷启动期（0–30 天）：自动 + 精准手动跑收录，合规积累评论（Vine 等），盯自然位起量；
   * 放量期（30–90 天）：核心词卡位、Deal/促销配合冲排名与新品销量占比；
   * 收割期（90 天+）：自然流量占比提升、ACOS 回落至目标以下、预算向高 ROAS 词集中；
   * 全程用 M1 的自然/广告曝光占比变化做"自然承接力"健康指标。

### M8-A 财务测算 【待人工确认口径】

> ⚠️ 本模块所有指标口径未经用户逐项确认前，一律输出占位符 + 确认清单，不自行假设公式/周期/假设。

**拆分待确认指标清单**（每项确认：公式、预测周期、成本项、周转/回款假设、数据源）：

1. **投资回报率（ROI）**：毛利 or 净利？含广告？资金占用怎么算？周期多长？
2. **资金流**：回款周期（第三方 14 天滚动 vs VC PO/Net-XX 差异）、备货资金峰值与占用时长；
3. **盈亏平衡测算**：按件 or 按月？是否含固定成本（团队/工具/账号）？
4. **备货量**：淡旺季系数、采购提前期、安全库存、周转目标（与 M6 联动）；
5. **止损点**：最大可亏损金额/月数、退出触发条件、库存残值假设。

**执行规定**：开工前把本清单交用户确认；确认后建测算模型；未确认项显式标记【待确认】，不打分、不参与加权。

### M8-B 供应链评估 【待人工确认口径】

> ⚠️ 同上：供应链维度含多个定性与定量对象，未确认口径前不填结论。

**拆分待确认指标清单**（确认：供应商样本、评分字段、权重、时间窗、证据来源）：

1. **供应链优势**（独家性/成本/产能/响应速度的评估维度与打分字段）；
2. **市场与线下反馈**（线下渠道信息源、采集方式、时间窗）；
3. **畅销款式与数据**（款式样本、销量数据口径、更新周期）；
4. **产业带与客单价匹配**（产业带位置、MOQ、价格阶梯）；
5. **参数与核心竞争力**（关键参数清单、与竞品对比维度与权重）。

**执行规定**：输出"供应商/款式样本采集表"框架 → 与用户确认评分字段权重后打分；无样本时标 U（未知），进待确认。

### M9 竞品拆解与差异化（TOP100 → TOP10 深筛）

**目标**：从"卖什么"到"为什么卖得好、我哪里能赢"。

**步骤**：

1. **TOP100 实时数据抓取**（AllyHub 批量，字段 §6.1）；
2. **Score 效率值排序**：Score ≈ 官方月销量 ÷ 评论数（低评论高销量的蓝海效率信号）。叠加筛选：非自营 + 官方月销 ≥50 + 评分 ≥4.0 + 有 BSR；
3. **TOP10 详情页实测验证**（10/10）：品牌/BSR/变体/五点/重量逐项实测纠正；上架时间不显示则标"页面未显示"；
4. **拆解表输出**（§6.2 列规范，含主图、核心卖点、差评/风险点）；
5. **差异化矩阵**：横向对比功能/材质/规格/价格/场景/评论痛点 → 竞品共性弱点、无人占位的卖点组合（切口）、我方独有优势（供应链/专利/独家资源，与 M8-B、M11 交叉验证）。

### M10 消费者洞察 VOC（实时抓取）

**目标**：用买家语言验证需求与切口。

1. **评论实时抓取**：TOP10 + 核心竞品差评与好评全量抓取（当前可见范围），保留原文；
2. **差评分析**：痛点聚类（质量/尺寸/漏水/色差/说明书/配件…）→ 差评 TOP3 痛点 + 频次 + 买家原话；
3. **好评分析**：好评 TOP3 卖点 + 频次 + 原话（不改写）；
4. **人群分析**：用途、场景、人口特征 → 人群画像卡（谁买/什么场景/为什么买/在意什么）；
5. **低评论高销量样本检查**：Score 高 ASIN 评论结构（"蓝海空位"还是"异常信号"，只提示不下结论）；
6. 输出差评机会代表 ASIN（供 M9 差异化与设计规避参考）。

### M11 知识产权检索（硬否决）

**检索范围（用户口径，固化）**：以用户确认的目标产品**核心外观和功能特征**为检索对象；检索 **DE、EP 及有效覆盖德国的欧盟外观设计**；发明、实用新型、外观设计**分类型输出**；只统计**快照日法律状态有效**、且经**权利要求或外观图人工确认与目标产品相关**的专利族；**相同 INPADOC 专利族只计一次**；输出有效专利族数量、代表公开号、权利人、法律状态、相关性证据、检索日期。

**步骤**：

1. **特征分解**：把目标产品拆成结构化检索要素（用途/结构/部件/功能/效果/材料/外观形态）；
2. **分类检索**：
   * 发明 + 实用新型（含 DE Gebrauchsmuster）：Espacenet（EP/DE）+ DPMAregister 核 DE 法律状态；
   * 外观设计：EUIPO eSearch（RCD，自动覆盖德国）+ 德国外观设计库；
   * 关键词 + 分类号（IPC/CPC + Locarno 外观分类）双通道；
3. **同族去重**：以 INPADOC 专利族为唯一键，同族只计一次；
4. **有效性过滤**：核对快照日法律状态 = 有效（申请中/失效不计；实用新型与外观的时点状态复核）；
5. **人工确认相关性**：Ally 输出证据摘要（公开号、权利要求项号/附图号、对应特征、风险区间）；**权利要求/外观图与目标产品的相关性确认必须由用户或专业法务复核后定级**；
6. **输出报告**（§6.5 字段）；
7. **结论定级**：高风险（命中强相关有效专利）→ 否决或先做规避设计；中风险 → 提交规避方案待确认；低风险 → 放行并记录证据备查。
