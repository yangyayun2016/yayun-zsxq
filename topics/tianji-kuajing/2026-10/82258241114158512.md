Amazon ASIN 竞品推广节奏分析:

亚马逊竞品ASIN推广节奏分析技能。当用户提到"竞品分析"、"ASIN分析"、"推广节奏"、"竞品拆解"、"竞品调研"、"对标分析"、"跟卖分析"，或提供一个ASIN要求分析其推广策略、定价策略、评论策略、流量结构、排名变化时，务必使用此技能。输出为一份完整的HTML竞品分析报告，包含趋势图表、月度拆解、风险判断等模块。即使用户只说"帮我看看这个ASIN"或"分析一下B0XXXXXXXX"，也应触发此技能。亚马逊竞品ASIN推广节奏分析

概述

本技能用于对亚马逊竞品ASIN进行系统化的推广节奏分析，输出一份结构化的HTML报告。报告涵盖从上架到成熟期的完整运营轨迹，帮助卖家还原竞品的定价、评论、流量、广告策略。

触发条件

用户提供一个或多个ASIN，要求分析竞品

用户要求分析某个竞品的推广节奏/运营策略

用户想了解竞品的定价、评论、流量、排名变化规律

用户说"帮我拆解这个竞品"、"看看这个ASIN怎么做起来的"等

数据获取

第一步：直接使用客户上传到附件的原始数据，使用SIF网页版插件 去下载该ASIN所有历史数据，给大模型

卖家精灵MCP / SIF MCP或者API 工具（补充）：

第二步：数据整理

将原始数据整理为以下结构化格式：

基础信息：ASIN, 标题, 品牌, 类目路径, 卖家名, 上架日期, 当前价格, 当前评分, 当前评论数

时间序列（日维度）：日期, 大类排名, 小类排名, 日销量, 成交价, LD价, Coupon价, 全部流量, 自然流量, 广告流量, 自然%, SP常规%, SP推荐%, SB%, SBV%

关键事件：首次上架, 首次出单, 首条评论, 首次改价, 首次DEAL, 首次COUPON, 首次PRIME, 首次卖家增加, 首次修改标题, 首次修改主图

报告生成

HTML报告结构

生成一个单文件HTML报告，使用内联CSS和Chart.js（CDN引入）。报告包含以下模块，按顺序排列：

模块1：报告头部

标题：\[ASIN\] 竞品前4个月推广节奏分析报告

分析周期：YYYY-MM-DD \~ YYYY-MM-DD

核心指标卡片（横排4个）：

* 前4月总销量 XXX

* 前4月销售额 XXX（带货币符号）

* 累计评论增长 XXX

* 大类最佳排名 XXX（BSR）

模块2：关键时间节点

用时间线（timeline）样式展示：

节点说明首次上架YYYY-MM-DD最早出单YYYY-MM-DD首条评论YYYY-MM-DD首次改价YYYY-MM-DD首次DEALYYYY-MM-DD，价格XXX首次COUPONYYYY-MM-DD首次PRIMEYYYY-MM-DD首次出单BuyBox价XXX首次卖家增加YYYY-MM-DD首次修改标题YYYY-MM-DD首次修改主图YYYY-MM-DD

模块3：核心趋势图表

使用Chart.js绘制以下图表：

图表A - 排名/成交价/评论数综合趋势（组合图）

X轴：日期

Y轴左：大类排名BSR（折线，反转轴，数值越低排名越好）

Y轴左：小类排名（折线）

Y轴右：成交价（折线）

Y轴右2：评论数（面积图）

注意：排名轴需要反转（值越小越靠上）

图表B - 月度销量结构对比（堆叠柱状图）

X轴：月份

三组柱：全部流量对应销量、自然流量对应销量、广告流量对应销量

图表C - 月度新增评论数（柱状图）

X轴：月份

Y轴：新增评论数

模块4：前4个月汇总表

表格形式，每行一个月：

月份策略标签销量成交价大类BSR最佳小类最佳评论数留评率广告费占比新增广告

策略标签自动判断逻辑：

第1个月：若成交价低于后续月份均值 → "低价切入+评论拉升"

第2-3个月：若排名波动<20% → "排名维持期"；否则 → "排名回落观察"

第4个月：若广告占比上升 → "广告调整+排名冲刺"

模块5：月度推广节奏拆解（核心模块）

每个月一个展开/收起的卡片，包含以下子模块：

MONTH N — 第N个月（起止日期）策略标签

■ 销量与排名

■ Listing策略

标题修改N次，主图修改N次，点击率优化动作描述

■ 价格策略

月初成交价XX → 月末成交价XX，月均成交价XX

BuyBox区间：XX \~ XX

关键改价点：日期=价格（列举所有改价事件）

LD活动N次

■ 评论策略

评论从X增至Y，月新增Z，留评率X%

评分X.X，评论质量判断（强/中/弱）

■ 流量策略

全部流量XXX

自然/广告占比：XX%/XX%

新增广告N次

SP常规/推荐占比：XX%/XX%

■ 风险判断（用颜色标记）

🟢 正常 / 🟡 需关注 / 🔴 高风险

判断规则：

* 留评率 > 3% → 🔴 需警惕刷单风险

模块6：效果总结

\# 亚马逊竞品 ASIN 推广节奏分析

\## 概述

本 skill 用于对亚马逊竞品 ASIN 进行系统化推广节奏分析，输出一份结构化的单文件 HTML 报告。报告涵盖从上架到成熟期的完整运营轨迹，帮助卖家还原竞品的定价、评论、流量、广告策略。

参考文档：\`references/report-spec.md\`（报告结构与模块规范）  

生成脚本：\`scripts/generate_report.py\`（HTML 报告生成器）

\---

\## 触发条件

\- 用户提供一个或多个 ASIN，要求分析竞品

\- 用户上传从卖家精灵等工具导出的竞品数据文件（TXT / CSV）

\- 用户说"帮我拆解这个竞品"、"分析 B0XXXXXXX 的推广节奏"等

\- 即使用户只说"帮我看看这个 ASIN"也应触发

\---

\## 执行步骤

\### 第一步：获取数据

优先使用用户上传的附件（TXT/CSV）。文件通常包含多张数据表，以固定标题行分隔：

\- \`全量明细\` / \`前4月明细\` / \`前8周明细\`

\- \`近N月聚合\` / \`前N月聚合\` / \`第N月聚合\` / \`第N周聚合\`

若用户未上传文件，告知需要先提供竞品数据文件，或通过卖家精灵等工具导出后上传。

\### 第二步：解析数据

调用 \`scripts/generate_report.py\` 完成解析与报告生成：

\`\`\`bash

python scripts/generate_report.py <数据文件路径>  \[--output <输出目录>\]

\`\`\`

脚本职责：

1\. 自动识别并分割数据文件中的多张表

2\. 整理为时间序列（日维度）和聚合维度数据

3\. 提取关键事件节点（首次上架、首次出单、首次改价等）

4\. 按报告规范生成单文件 HTML

\### 第三步：输出报告

\- 文件名：\`{ASIN}\_竞品分析报告\_{日期}.html\`

\- 保存路径：\`/mnt/user-data/outputs/\`

\- 完成后将文件上传到 Library，并向用户展示报告摘要（核心指标 + 策略亮点 + 风险提示）

\---

\## 数据不足处理

\- 缺失字段显示 \`—\` 或 \`数据缺失\`，不得编造数据

\- 在报告末尾注明哪些字段未获取到

\- 建议用户通过其他渠道补充

\---

\## 错误处理

| 场景 | 处理方式 |

|------|----------|

| 文件格式无法识别 | 提示支持 TXT/CSV，请重新导出 |

| 关键列缺失（如日期、销量） | 跳过该模块，报告中注明 |

| ASIN 与文件数据不符 | 优先使用文件中的 ASIN 字段 |

| Chart.js CDN 无法加载 | 报告内嵌降级提示，表格数据仍正常显示 |
