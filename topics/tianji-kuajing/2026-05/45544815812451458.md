一个真正可以落地的 **“亚马逊广告止损版 Skill”** 详细跑一遍。这个 Skill 的作用不是简单粗暴地关广告，而是每天/每周读取广告数据，判断哪些词、ASIN、target、campaign 正在浪费钱，然后输出：**否词、否 ASIN、暂停、降 bid、降预算、继续观察、人工复核，监督， 复盘**。

---

# 一、Skill 名称

**Amazon PPC Stop-Loss Skill：广告止损、否词、否 ASIN 与预算保护系统**

核心目标：

```text
减少无效点击
控制广告流血
识别亏损 target
自动生成否词/暂停/降价建议
避免误杀潜力词
为后续扩量 Skill 提供干净数据
```

Amazon 官方也说明，Search Term Report 可以用来识别高表现搜索词，也可以用来创建不符合目标的 negative keywords 或 product targets；Sponsored Products 也支持 negative exact、negative phrase，以及 negative product targeting。Amazon 同时建议，在把关键词加入 negative target 之前，最好至少观察到约 20 次点击。([Amazon Ads][1])

# 三、Skill 的核心参数

先设定参数，不然后面无法判断“浪费”。

## 1. 基础参数

```text
分析周期：最近 7 天
辅助周期：最近 14 天 / 30 天/ 90 天
最小观察点击：20 clicks
默认止损点击：35 clicks
最低花费判断：Max CPA
强制花费止损：1.5 × Max CPA
默认 Target ACOS：25% 或根据产品毛利设置
默认 Break-even ACOS：产品毛利率
```

Amazon 官方建议日预算可以从 $10 或等值货币开始，实际可随时调整；你前面说的“每天 $10，7 天 $70 不出单关闭”可以作为 campaign 级别的预算保护规则。([Amazon Ads][2])

---

## 2. 毛利与 ACOS 参数

```text
Break-even ACOS = 毛利率
Target ACOS = Break-even ACOS × 安全系数
```

例如：

```text
售价 = $25
产品成本 + FBA + 佣金 + 其他费用 = $16
毛利 = $9
毛利率 = 36%

Break-even ACOS = 36%
Target ACOS = 25% 或 30%
```

解释：

```text
ACOS 低于 Target ACOS：健康
ACOS 在 Target ACOS 和 Break-even ACOS 之间：可接受但需优化
ACOS 高于 Break-even ACOS：广告亏损
ACOS 高于 100%：严重流血
```

# 四、Skill 计算字段

每次导入数据后，先计算这些字段。

```text
CTR = Clicks / Impressions
CVR = Orders / Clicks
CPC = Spend / Clicks
CPA = Spend / Orders
ACOS = Spend / Sales
ROAS = Sales / Spend
Max CPA = Selling Price × Target ACOS
Break-even CPA = Selling Price × Break-even ACOS
Wasted Spend Ratio = Spend / Max CPA
目标CPC=ACOS*客单价*转化率
公式，CPC=ACOS*售价*CVR，CPA= CPC/CVR，ACOS=CPA/售价，
用全部毛利 去做广告，你的毛利率=ACOS之间关系，

举例比如我这个产品利润就只有6美金，如果转化率是8%，前期不考虑自然订单的情况下，你12.5个点击才能出1单，那么你的cpc就只能做到0.48是刚好的
举例比如我这个产品利润就只有6美金，如果转化率是8%，前期不考虑自然订单的情况下，你12.5个点击才能出1单，那么你的cpc就只能做到0.48是刚好的
```

如果 Orders = 0：

```text
CPA = 无限大
ACOS = 无限大
```

不要因为 ACOS 空白就认为安全。
**Spend > 0 且 Orders = 0，就是潜在浪费。**

# 五、止损 Skill 的判断层级

不要直接从 campaign 开始关。正确顺序是：

```text
搜索词层级
↓
关键词 / ASIN target 层级
↓
广告组层级
↓
Campaign 层级
```

原因是：
一个 campaign 流血，可能只是里面 1 个词或 1 个 ASIN 在烧钱。直接关 campaign 会误杀其他有效流量。

---

# 六、规则 1：搜索词无订单止损

这是最核心的规则。

## 规则逻辑

```text
IF Customer Search Term clicks >= 35
AND Orders = 0
AND Spend >= Max CPA
THEN 建议 Negative Exact
```

更稳健版本：

```text
IF Customer Search Term clicks >= max(20, 动态点击阈值)亚马逊建议 点击20次再观察，这个版本更稳健
AND Orders = 0
AND Spend >= Max CPA
THEN Negative Exact
```

Amazon 官方建议加否定目标前至少观察到 20 次点击，所以 Skill 里默认不要在 5 次、10 次点击时就自动否词，除非这个词明显不相关。([Amazon Ads][3])

---

## 示例

假设：

```text
产品售价 = $25
Target ACOS = 25%
Max CPA = $6.25
```

某搜索词：

```text
Search Term: pink lunch box for kids
Clicks: 38
Spend: $9.20
Orders: 0
Sales: $0
```

判断：

```text
Clicks >= 35
Spend >= $6.25
Orders = 0
```

输出：

```text
Action: Add Negative Exact
Reason: 35+ clicks no order, spend exceeded Max CPA
Risk Level: High
Review Required: Yes
```

---

# 七、规则 2：搜索词明显不相关止损（判断相关性，完全不相关直接否，不需要35次）

有些词不需要等 35 点击。
比如你卖高端新品，但搜索词里出现：

```text
free
used
second hand
replacement parts
manual
repair
cheap
DIY
pdf
instructions
wholesale
template
```

这些词是否要否，要看产品，但如果明显不相关，可以早一点处理。

## 规则逻辑

```text
IF Search Term contains irrelevant root word
AND Clicks >= 5
AND Orders = 0
THEN 人工复核后 Negative Phrase 或 Negative Exact
```

## Exact 和 Phrase 的区别

Amazon 的 negative exact 是阻止广告出现在完全匹配或接近变体的查询上；negative phrase 是阻止广告出现在包含完整短语或接近变体的查询上。Negative phrase 杀伤面更大，所以 Skill 默认优先 exact。([Amazon Ads][4])

## 输出建议

```text
Search Term: free lunch box
Clicks: 8
Spend: $2.40
Orders: 0

Action: Negative Phrase
Negative Keyword: free
Reason: 明显低购买意图词
Review Required: Yes
```

注意：
如果卖的是“cheap storage bins”，那 cheap 不一定要否。
所以这类规则必须人工复核。

---

# 八、规则 3：搜索词有订单但亏损

有订单的词，不要轻易否掉。
应该先降 bid，而不是直接否词。

## 规则逻辑

```text
IF Orders >= 1
AND ACOS > Break-even ACOS
AND Orders < 3
THEN 降 bid 20%–30%，继续观察
```

```text
IF Orders >= 3
AND ACOS > Break-even ACOS
THEN 降 bid 30%–50% 或暂停 target
```

```text
IF Orders >= 3
AND ACOS > Target ACOS × 2
THEN 暂停 target，人工复核是否否词
```

---

## 示例

```text
Search Term: insulated lunch bag women
Clicks: 42
Spend: $24
Orders: 2
Sales: $50
ACOS: 48%
Target ACOS: 25%
Break-even ACOS: 35%
```

判断：

```text
有订单
但 ACOS 48% > Break-even ACOS 35%
订单数只有 2
```

输出：

```text
Action: Lower Bid 30%
Reason: Converted but unprofitable
Do Not Negative Yet
Review Required: No
```

为什么不直接否词？
因为这个词能转化，说明相关性可能是对的，只是 bid 太高、价格不合适、listing 转化弱，或者广告位太贵。

---

# 九、规则 4：关键词 Target 止损

Search Term 是顾客实际搜的词。
Targeting 是你投放的关键词或 ASIN。

一个 target 下面可能匹配出很多 search terms，所以 target 级别要看整体表现。

## 无订单 target 止损

```text
IF Target clicks >= 35
AND Orders = 0
AND Spend >= Max CPA
THEN Pause Target
```

## 有订单但亏损

```text
IF Target Orders >= 2
AND Target ACOS > Break-even ACOS
THEN Lower Bid 20%–40%
```

## 严重亏损

```text
IF Target Orders >= 3
AND Target ACOS > Target ACOS × 2
THEN Pause Target
```

---

## 示例

```text
Targeting: lunch box
Match Type: Broad
Clicks: 120
Spend: $58
Orders: 2
Sales: $45
ACOS: 129%
```

判断：

```text
有订单，但 ACOS 极高
Broad 可能匹配了大量低质量搜索词
```

输出：

```text
Action 1: Lower Bid 40%
Action 2: 从 Search Term Report 里提取浪费词做 Negative Exact
Action 3: 不建议直接暂停整个 broad，除非 14 天仍亏损
```

---

# 十、规则 5：ASIN / Product Target 止损

ASIN 定投也会流血。
某些竞品页面点击很多，但你的产品价格、评分、图片、coupon 不占优势，就会一直烧钱不出单。

## ASIN 无订单止损

```text
IF Target ASIN clicks >= 30
AND Orders = 0
AND Spend >= Max CPA
THEN Negative Product Target 或 Pause Product Target
```

Amazon 官方资料也说明，negative product targeting 可以排除你不希望广告展示的商品或品牌，从而避免出现在无效位置。([Amazon Ads][2])

---

## ASIN 有订单但亏损

```text
IF Target ASIN Orders >= 2
AND ACOS > Break-even ACOS
THEN Lower Bid 20%–40%
```

## ASIN 严重亏损

```text
IF Target ASIN Orders >= 3
AND ACOS > Target ACOS × 2
THEN Pause ASIN Target
```

---

## 示例

```text
Target ASIN: B0XXXXXXX1
Clicks: 33
Spend: $11.40
Orders: 0
Max CPA: $6.25
```

输出：

```text
Action: Negative Product Target
Reason: ASIN target generated 30+ clicks, no orders, spend exceeded Max CPA
Review Required: Yes
```

---

# 十一、规则 6：Campaign 级别止损

Campaign 不应该是第一层止损，而是最后一层。

## 你的规则

```text
每天预算 $10
7 天预算 $70
7 天不出单关闭
```

可以优化成：

```text
IF Campaign Spend >= 7 × Daily Budget × 80%
AND Orders = 0
THEN 检查是否由少数 target 流血
```

如果是少数 target 流血：

```text
Pause target
不要关 campaign
```

如果整个 campaign 都没有有效 target：

```text
Pause campaign
或 Daily Budget 降到 $1–$3
```

---

## Campaign 关闭规则

```text
IF Campaign Spend >= 7-day Budget
AND Orders = 0
AND Top 80% Spend Targets also Orders = 0
THEN Pause Campaign
```

## Campaign 降预算规则

```text
IF Campaign ACOS > Break-even ACOS
AND Orders >= 2
AND 仍有部分有效 target
THEN Daily Budget 降低 30%–50%
```

## Campaign 保留规则

```text
IF Campaign 里有 1–2 个高转化词
AND 整体 ACOS 高
THEN 不关 campaign
先把浪费 search terms 否掉
再把高转化词转移到 Exact Campaign
```

---

# 十二、规则 7：新品保护期

新品广告不能太早止损。前期不要大量否词，避免流量的波动，削减
新品没有 review、没有排名、listing 还在学习阶段，前 7 天数据可能不稳定。

## 新品保护参数

```text
新品定义：上线 ≤ 14 天
或 Review < 5
或 总广告订单 < 5
```

## 新品期规则

```text
IF New Product = Yes
AND Clicks < 50
AND Spend < 2 × Max CPA
THEN Observe，不自动暂停
```

但明显不相关搜索词仍然可以否：

```text
IF Search Term clearly irrelevant
THEN Negative Exact / Phrase after review
```

---

# 十三、规则 8：防止误杀的安全机制

这个 Skill 必须有“误杀保护”。

## 不自动否的情况

以下情况不要自动否词：

```text
有订单
有加购数据但没有订单
搜索词高度相关但样本量小
新品期
促销前后数据异常
Prime Day / 黑五 / 网一期间
库存断货期间
Listing 被改动期间
价格突然上升期间
```

## 必须人工复核的动作

```text
Negative Phrase
Campaign Pause
ASIN Negative
高花费 Exact Keyword Pause
品牌词否定
竞品词否定
类目词否定
```

## 可以自动执行的动作

```text
低风险降 bid
Negative Exact 候选
暂停明显无订单 target 候选
输出 bulk sheet 草稿
```

---

# 十四、Skill 的动作优先级

当一个对象同时满足多个规则时，按这个顺序处理。

```text
1. 明显不相关 → Negative Exact / Phrase
2. 无订单且花费超过 Max CPA → Negative Exact 或 Pause Target
3. 有订单但亏损 → Lower Bid
4. Campaign 整体无订单 → 检查 target 后再暂停 campaign
5. 数据不足 → Observe
6. 新品保护 → 延长观察
```

# 三、Skill 的核心参数

先设定参数，不然后面无法判断“浪费”。

## 1. 基础参数

```text

强制花费止损：1.5 × Max CPA
默认 Target ACOS：25% 或根据产品毛利设置
默认 Break-even ACOS：产品毛利率
```

Amazon 官方建议日预算可以从 $10 或等值货币开始，实际可随时调整；你前面说的“每天 $10，7 天 $70 不出单关闭”可以作为 campaign 级别的预算保护规则。([Amazon Ads][2])

## 2. 毛利与 ACOS 参数

```text
Break-even ACOS = 毛利率
Target ACOS = Break-even ACOS × 安全系数
```

例如：

```text
售价 = $25
产品成本 + FBA + 佣金 + 其他费用 = $16
毛利 = $9
毛利率 = 36%

Break-even ACOS = 36%
Target ACOS = 25% 或 30%
```

解释：

```text
ACOS 低于 Target ACOS：健康
ACOS 在 Target ACOS 和 Break-even ACOS 之间：可接受但需优化
ACOS 高于 Break-even ACOS：广告亏损
ACOS 高于 100%：严重流血
```

# 四、Skill 计算字段

```text

ACOS = Spend / Sales
ROAS = Sales / Spend

Wasted Spend Ratio = Spend / Max CPA

# 五、止损 Skill 的判断层级

不要直接从 campaign 开始关。正确顺序是：

```text
搜索词层级
↓
关键词 / ASIN target 层级
↓
广告组层级
↓
Campaign 层级
```

原因是：
一个 campaign 流血，可能只是里面 1 个词或 1 个 ASIN 在烧钱。直接关 campaign 会误杀其他有效流量。

# 六、规则 1：搜索词无订单止损

这是最核心的规则。

## 规则逻辑

```text
IF Customer Search Term clicks >= 35
AND Orders = 0
AND Spend >= Max CPA
THEN 建议 Negative Exact
```

更稳健版本：

```text
IF Customer Search Term clicks >= max(20, 动态点击阈值)亚马逊建议 点击20次再观察，这个版本更稳健
AND Orders = 0
AND Spend >= Max CPA
THEN Negative Exact
```

Amazon 官方建议加否定目标前至少观察到 20 次点击，所以 Skill 里默认不要在 5 次、10 次点击时就自动否词，除非这个词明显不相关。([Amazon Ads][3])

## 示例

```text

Clicks: 38
Spend: $9.20
Orders: 0
Sales: $0

判断：

```text
Clicks >= 35
Spend >= $6.25
Orders = 0
```

输出：

Risk Level: High
Review Required: Yes

# 七、规则 2：搜索词明显不相关止损（判断相关性，完全不相关直接否，不需要35次）

有些词不需要等 35 点击。
比如你卖高端新品，但搜索词里出现：

```text

used
second hand
replacement parts
manual
repair
cheap

pdf

wholesale

```

这些词是否要否，要看产品，但如果明显不相关，可以早一点处理。

## 规则逻辑

```text
IF Search Term contains irrelevant root word
AND Clicks >= 5
AND Orders = 0
THEN 人工复核后 Negative Phrase 或 Negative Exact
```

## Exact 和 Phrase 的区别

Amazon 的 negative exact 是阻止广告出现在完全匹配或接近变体的查询上；negative phrase 是阻止广告出现在包含完整短语或接近变体的查询上。Negative phrase 杀伤面更大，所以 Skill 默认优先 exact。([Amazon Ads][4])

## 输出建议

```text

Clicks: 8
Spend: $2.40
Orders: 0

Action: Negative Phrase
Negative Keyword: free
Reason: 明显低购买意图词
Review Required: Yes
```

注意：
如果卖的是“cheap storage bins”，那 cheap 不一定要否。
所以这类规则必须人工复核。

# 八、规则 3：搜索词有订单但亏损

有订单的词，不要轻易否掉。
应该先降 bid，而不是直接否词。

## 规则逻辑

```text
IF Orders >= 1
AND ACOS > Break-even ACOS
AND Orders < 3
THEN 降 bid 20%–30%，继续观察
```

```text
IF Orders >= 3
AND ACOS > Break-even ACOS
THEN 降 bid 30%–50% 或暂停 target
```

```text
IF Orders >= 3
AND ACOS > Target ACOS × 2
THEN 暂停 target，人工复核是否否词
```

---

## 示例

```text
Search Term: insulated lunch bag women
Clicks: 42
Spend: $24
Orders: 2
Sales: $50
ACOS: 48%
Target ACOS: 25%
Break-even ACOS: 35%
```

判断：

```text
有订单
但 ACOS 48% > Break-even ACOS 35%
订单数只有 2
```

输出：

```text
Action: Lower Bid 30%
Reason: Converted but unprofitable
Do Not Negative Yet
Review Required: No
```

为什么不直接否词？
因为这个词能转化，说明相关性可能是对的，只是 bid 太高、价格不合适、listing 转化弱，或者广告位太贵。

# 九、规则 4：关键词 Target 止损

Search Term 是顾客实际搜的词。
Targeting 是你投放的关键词或 ASIN。

一个 target 下面可能匹配出很多 search terms，所以 target 级别要看整体表现。

## 无订单 target 止损

```text
IF Target clicks >= 35
AND Orders = 0
AND Spend >= Max CPA
THEN Pause Target
```

## 有订单但亏损

```text
IF Target Orders >= 2
AND Target ACOS > Break-even ACOS
THEN Lower Bid 20%–40%
```

## 严重亏损

```text
IF Target Orders >= 3
AND Target ACOS > Target ACOS × 2
THEN Pause Target
```

Targeting: lunch box

Orders: 2

```text

Broad 可能匹配了大量低质量搜索词

输出：

```text

Action 2: 从 Search Term Report 里提取浪费词做 Negative Exact
Action 3: 不建议直接暂停整个 broad，除非 14 天仍亏损
```

# 十、规则 5：ASIN / Product Target 止损

ASIN 定投也会流血。
某些竞品页面点击很多，但你的产品价格、评分、图片、coupon 不占优势，就会一直烧钱不出单。

## ASIN 无订单止损

```text
IF Target ASIN clicks >= 30
AND Orders = 0
AND Spend >= Max CPA
THEN Negative Product Target 或 Pause Product Target
```

Amazon 官方资料也说明，negative product targeting 可以排除你不希望广告展示的商品或品牌，从而避免出现在无效位置。([Amazon Ads][2])

---

## ASIN 有订单但亏损

```text
IF Target ASIN Orders >= 2
AND ACOS > Break-even ACOS
THEN Lower Bid 20%–40%
```

## ASIN 严重亏损

```text
IF Target ASIN Orders >= 3
AND ACOS > Target ACOS × 2
THEN Pause ASIN Target
```

---

## 示例

```text
Target ASIN: B0XXXXXXX1
Clicks: 33
Spend: $11.40
Orders: 0
Max CPA: $6.25
```

输出：

```text

# 十一、规则 6：Campaign 级别止损

Campaign 不应该是第一层止损，而是最后一层。

## 你的规则

```text
每天预算 $10
7 天预算 $70
7 天不出单关闭
```

可以优化成：

```text
IF Campaign Spend >= 7 × Daily Budget × 80%
AND Orders = 0
THEN 检查是否由少数 target 流血
```

如果是少数 target 流血：

```text
Pause target
不要关 campaign
```

如果整个 campaign 都没有有效 target：

```text
Pause campaign
或 Daily Budget 降到 $1–$3
```

---

## Campaign 关闭规则

```text
IF Campaign Spend >= 7-day Budget
AND Orders = 0
AND Top 80% Spend Targets also Orders = 0
THEN Pause Campaign
```

## Campaign 降预算规则

```text
IF Campaign ACOS > Break-even ACOS
AND Orders >= 2

## 2. 毛利与 ACOS 参数

```text

```text

```

解释：

```text
ACOS 低于 Target ACOS：健康
ACOS 在 Target ACOS 和 Break-even ACOS 之间：可接受但需优化
ACOS 高于 Break-even ACOS：广告亏损
ACOS 高于 100%：严重流血
```

# 四、Skill 计算字段

Wasted Spend Ratio = Spend / Max CPA

```

原因是：
一个 campaign 流血，可能只是里面 1 个词或 1 个 ASIN 在烧钱。直接关 campaign 会误杀其他有效流量。

# 六、规则 1：搜索词无订单止损

这是最核心的规则。

## 规则逻辑

```text
IF Customer Search Term clicks >= 35
AND Orders = 0
AND Spend >= Max CPA
THEN 建议 Negative Exact
```

更稳健版本：

```text
IF Customer Search Term clicks >= max(20, 动态点击阈值)亚马逊建议 点击20次再观察，这个版本更稳健
AND Orders = 0
AND Spend >= Max CPA
THEN Negative Exact
```

Amazon 官方建议加否定目标前至少观察到 20 次点击，所以 Skill 里默认不要在 5 次、10 次点击时就自动否词，除非这个词明显不相关。([Amazon Ads][3])

---

## 示例

假设：

```text
产品售价 = $25
Target ACOS = 25%
Max CPA = $6.25
```

某搜索词：

```text
Search Term: pink lunch box for kids
Clicks: 38
Spend: $9.20
Orders: 0
Sales: $0
```

判断：

```text
Clicks >= 35
Spend >= $6.25
Orders = 0
```

输出：

```text
Action: Add Negative Exact
Reason: 35+ clicks no order, spend exceeded Max CPA
Risk Level: High
Review Required: Yes
```

# 七、规则 2：搜索词明显不相关止损（判断相关性，完全不相关直接否，不需要35次）

有些词不需要等 35 点击。
比如你卖高端新品，但搜索词里出现：

```text
free
used
second hand
replacement parts
manual
repair
cheap
DIY
pdf
instructions
wholesale
template
```

这些词是否要否，要看产品，但如果明显不相关，可以早一点处理。

## 规则逻辑

```text
IF Search Term contains irrelevant root word
AND Clicks >= 5
AND Orders = 0
THEN 人工复核后 Negative Phrase 或 Negative Exact
```

## Exact 和 Phrase 的区别

Amazon 的 negative exact 是阻止广告出现在完全匹配或接近变体的查询上；negative phrase 是阻止广告出现在包含完整短语或接近变体的查询上。Negative phrase 杀伤面更大，所以 Skill 默认优先 exact。([Amazon Ads][4])

## 输出建议

```text
Search Term: free lunch box
Clicks: 8
Spend: $2.40
Orders: 0

Action: Negative Phrase
Negative Keyword: free
Reason: 明显低购买意图词
Review Required: Yes
```

注意：
如果卖的是“cheap storage bins”，那 cheap 不一定要否。
所以这类规则必须人工复核。

---

# 八、规则 3：搜索词有订单但亏损

有订单的词，不要轻易否掉。
应该先降 bid，而不是直接否词。

## 规则逻辑

```text
IF Orders >= 1
AND ACOS > Break-even ACOS
AND Orders < 3
THEN 降 bid 20%–30%，继续观察
```

```text
IF Orders >= 3
AND ACOS > Break-even ACOS
THEN 降 bid 30%–50% 或暂停 target
```

```text
IF Orders >= 3
AND ACOS > Target ACOS × 2
THEN 暂停 target，人工复核是否否词
```

---

## 示例

```text
Search Term: insulated lunch bag women
Clicks: 42
Spend: $24
Orders: 2
Sales: $50
ACOS: 48%
Target ACOS: 25%
Break-even ACOS: 35%
```

判断：

```text
有订单
但 ACOS 48% > Break-even ACOS 35%
订单数只有 2
```

输出：

```text
Action: Lower Bid 30%
Reason: Converted but unprofitable
Do Not Negative Yet
Review Required: No
```

为什么不直接否词？
因为这个词能转化，说明相关性可能是对的，只是 bid 太高、价格不合适、listing 转化弱，或者广告位太贵。

---

# 九、规则 4：关键词 Target 止损

Search Term 是顾客实际搜的词。
Targeting 是你投放的关键词或 ASIN。

一个 target 下面可能匹配出很多 search terms，所以 target 级别要看整体表现。

## 无订单 target 止损

```text
IF Target clicks >= 35
AND Orders = 0
AND Spend >= Max CPA
THEN Pause Target
```

## 有订单但亏损

```text
IF Target Orders >= 2
AND Target ACOS > Break-even ACOS
THEN Lower Bid 20%–40%
```

## 严重亏损

```text
IF Target Orders >= 3
AND Target ACOS > Target ACOS × 2
THEN Pause Target
```

---

## 示例

```text
Targeting: lunch box
Match Type: Broad
Clicks: 120
Spend: $58
Orders: 2
Sales: $45
ACOS: 129%
```

判断：

```text
有订单，但 ACOS 极高
Broad 可能匹配了大量低质量搜索词
```

输出：

```text
Action 1: Lower Bid 40%
Action 2: 从 Search Term Report 里提取浪费词做 Negative Exact
Action 3: 不建议直接暂停整个 broad，除非 14 天仍亏损
```

---

# 十、规则 5：ASIN / Product Target 止损

ASIN 定投也会流血。
某些竞品页面点击很多，但你的产品价格、评分、图片、coupon 不占优势，就会一直烧钱不出单。

## ASIN 无订单止损

```text
IF Target ASIN clicks >= 30
AND Orders = 0
AND Spend >= Max CPA
THEN Negative Product Target 或 Pause Product Target
```

Amazon 官方资料也说明，negative product targeting 可以排除你不希望广告展示的商品或品牌，从而避免出现在无效位置。([Amazon Ads][2])

---

## ASIN 有订单但亏损

```text
IF Target ASIN Orders >= 2
AND ACOS > Break-even ACOS
THEN Lower Bid 20%–40%
```

## ASIN 严重亏损

```text
IF Target ASIN Orders >= 3
AND ACOS > Target ACOS × 2
THEN Pause ASIN Target
```

---

## 示例

```text
Target ASIN: B0XXXXXXX1
Clicks: 33
Spend: $11.40
Orders: 0
Max CPA: $6.25
```

输出：

```text
Action: Negative Product Target
Reason: ASIN target generated 30+ clicks, no orders, spend exceeded Max CPA
Review Required: Yes
```

# 十一、规则 6：Campaign 级别止损

Campaign 不应该是第一层止损，而是最后一层。

## 你的规则

```text
每天预算 $10
7 天预算 $70
7 天不出单关闭
```

可以优化成：

```text
IF Campaign Spend >= 7 × Daily Budget × 80%
AND Orders = 0
THEN 检查是否由少数 target 流血
```

如果是少数 target 流血：

```text
Pause target
不要关 campaign
```

如果整个 campaign 都没有有效 target：

```text
Pause campaign
或 Daily Budget 降到 $1–$3
```

---

## Campaign 关闭规则

```text
IF Campaign Spend >= 7-day Budget
AND Orders = 0
AND Top 80% Spend Targets also Orders = 0
THEN Pause Campaign
```

## Campaign 降预算规则

```text
IF Campaign ACOS > Break-even ACOS
AND Orders >= 2
AND 仍有部分有效 target
THEN Daily Budget 降低 30%–50%
```

## Campaign 保留规则

```text
IF Campaign 里有 1–2 个高转化词
AND 整体 ACOS 高
THEN 不关 campaign
先把浪费 search terms 否掉
再把高转化词转移到 Exact Campaign
```

---

# 十二、规则 7：新品保护期

新品广告不能太早止损。前期不要大量否词，避免流量的波动，削减
新品没有 review、没有排名、listing 还在学习阶段，前 7 天数据可能不稳定。

## 新品保护参数

```text
新品定义：上线 ≤ 14 天
或 Review < 5
或 总广告订单 < 5
```

## 新品期规则

```text
IF New Product = Yes
AND Clicks < 50
AND Spend < 2 × Max CPA
THEN Observe，不自动暂停
```

但明显不相关搜索词仍然可以否：

```text
IF Search Term clearly irrelevant
THEN Negative Exact / Phrase after review
```

# 十三、规则 8：防止误杀的安全机制

这个 Skill 必须有“误杀保护”。

## 不自动否的情况

以下情况不要自动否词：

```text
有订单
有加购数据但没有订单
搜索词高度相关但样本量小
新品期
促销前后数据异常
Prime Day / 黑五 / 网一期间
库存断货期间
Listing 被改动期间
价格突然上升期间
```

## 必须人工复核的动作

```text
Negative Phrase
Campaign Pause
ASIN Negative
高花费 Exact Keyword Pause
品牌词否定
竞品词否定
类目词否定
```

## 可以自动执行的动作

```text
低风险降 bid
Negative Exact 候选
暂停明显无订单 target 候选
输出 bulk sheet 草稿
```

# 十四、Skill 的动作优先级

当一个对象同时满足多个规则时，按这个顺序处理。

```text
1. 明显不相关 → Negative Exact / Phrase
2. 无订单且花费超过 Max CPA → Negative Exact 或 Pause Target
3. 有订单但亏损 → Lower Bid
4. Campaign 整体无订单 → 检查 target 后再暂停 campaign
5. 数据不足 → Observe
6. 新品保护 → 延长观察
```

# 二十一、这个 Skill 最终输出的判断逻辑

一句话总结：

```text
无订单 + 点击够 + 花费够 = 止损
有订单 + ACOS 高 = 降 bid
明显不相关 = 否词
ASIN 点击多无单 = 否 ASIN
Campaign 花光预算无单 = 暂停候选
数据不足 = 继续观察
```

最适合你的第一版止损逻辑是：

```text
最近 7 天：
- 35 点击不出单，且花费超过 Max CPA → 否 exact 或暂停 target
- 7 天花费达到预算上限仍 0 单 → 暂停 campaign 候选
- ACOS > Break-even ACOS → 降 bid
- ACOS > 100% 且订单数 ≥ 3 → 暂停 target 候选
- ASIN 30 点击不出单 → Negative Product 候选
- 明显不相关词 → 人工复核后 Negative Phrase
```

这样这个 Skill 就不是单纯的“关广告工具”，而是一个完整的 **PPC 防流血系统**：
它会优先从最细颗粒度止损，减少广告浪费，同时保留还可能转化的流量。
